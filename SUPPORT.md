# Getting help

CertiStack Community Edition is supported on a best-effort basis, with no response-time commitment. Support beyond best
effort is agreed in a signed order: sales@certistack.dev.

| I want to | Go to |
| --- | --- |
| Get started | [Quickstart](https://certistack.dev/docs/quickstart/), then [Plans](https://certistack.dev/docs/plan-reference/) |
| Understand an error or a failed run | [Troubleshooting](https://certistack.dev/docs/troubleshooting/) |
| Ask a question or share results | [GitHub Discussions](https://github.com/cliftcloud/certistack/discussions) |
| Report a reproducible bug | [Open an issue](https://github.com/cliftcloud/certistack/issues/new/choose) |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md); never in a public issue |
| Ask about the Enterprise Edition | [certistack.dev](https://certistack.dev/#licensing) or sales@certistack.dev |

Before you post, run the failing command with `--debug`, note the output of `certistack version` and your Proxmox VE
and PBS versions, and remove credentials, repository strings, private key paths and anything from a real customer
environment.
